Q : Explain in your own words (3-4 lines) how React's Virtual DOM makes updating the UI faster compared to traditional DOM manipulation.

React's Virtual DOM is a lightweight in-memory copy of the actual DOM. When state changes, React first updates this virtual copy and compares ("diffs") it against the previous version to figure out exactly what changed, rather than immediately touching the real DOM. It then batches all the necessary changes and applies only those minimal updates to the real DOM in one go. This is faster than traditional DOM manipulation because direct DOM operations are expensive (triggering layout recalculations and repaints), while diffing in memory and updating selectively avoids unnecessary, costly re-renders.
