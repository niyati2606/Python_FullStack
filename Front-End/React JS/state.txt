Function Component:
	A function component is a React component written as a plain JavaScript function that returns JSX

Ex : 
const functionComponent = () => {
	return(
		//HTML code
	)
}

export default functioncomponenet


Just a function — no class, no extends, no render()
Uses hooks (useState, useEffect, etc.) instead of this.state	
it is easier to read nad maintain
less in code compare to class
there is no need to declare constructor

In a function component, props are passed as an argument to the function and are used to receive data from the parent component.

Hooks in React are special functions that let you use React features (like state and lifecycle methods) inside functional components,
without needing to write a class.

For example:

useState — functional component hold and update state
useEffect — run side effects (like API calls, subscriptions) after render
